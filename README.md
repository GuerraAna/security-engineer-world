# Security Engineer World

Documentação pessoal de estudos da trilha de **Security Engineering** (Foundation → Trainee → Expert → Master), com base no treinamento e nas documentações oficiais. Site estático com [Docusaurus](https://docusaurus.io).

```bash
npm install    # dependências
npm start      # dev server (porta 3000)
npm run build  # build de produção (validar antes de commitar)
npm run serve  # serve o build localmente
```

Projeto irmão: [react-native-world](https://github.com/GuerraAna/react-native-world).
